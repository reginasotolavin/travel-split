# Travel Split

Travel Split is a collaborative workspace for planning trips, researching destinations, and organizing travel decisions in one place.

- **Live app:** [travel-split-gamma.vercel.app](https://travel-split-gamma.vercel.app)
- **Research workspace:** [Open /research](https://travel-split-gamma.vercel.app/research)
- **Repository:** [github.com/reginasotolavin/travel-split](https://github.com/reginasotolavin/travel-split)

## Tech Stack

- [Next.js](https://nextjs.org)
- [Tailwind CSS](https://tailwindcss.com)
- [Supabase](https://supabase.com)
- [Vercel](https://vercel.com)

## Run Locally

Install dependencies, then start the development server:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
